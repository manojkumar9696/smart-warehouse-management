Project Overview & Objectives

Operational Challenges Solved

  • Zero Real-Time Counts: Inability to view consolidated inventory levels across distinct physical hubs, causing mismatches.
  • Slow Picking Times: Lack of precise physical shelf logging slows down retrieval routes for warehouse operators.
  • Zero Accountability: No chronological audit ledgers capturing stock transfer actions or manual inventory adjustments.

Intelligent Solution Benefits

  • Consolidated Dashboard: Instantly inspect live balances, categories, and alerts from a single operational portal.
  • Granular Coordinate Maps: Assign and modify specific Rack, Shelf, and Bin coordinates for efficient routing.
  • Predictive Demand Engine: Uses sales velocity and seasonal indicators to suggest optimal procurement buy-orders.

Core System Features

Secure RBAC Gateway

  • Role Safeguards: Differentiated dashboards and endpoints based on Admin, Manager, and Employee configurations.
  • JWT Session Keys: Stateless validation via secure request authorization headers.
  • bcryptjs Hashing: Strong cryptographic barriers protecting credentials.
  • REST API Protection: Route middleware verifying role scopes on all write transactions.

Shelf Location Mapping

  • 3D Placement Matrix: Catalog item positions by Rack identifier, Shelf level, and Bin box.
  • Multi-Warehouse Hubs: Maintain separate inventory states for regional warehouses.
  • Live Balances Sync: Layout maps update automatically when shipments and transfers are executed.
  • Interactive Adjustments: Easily adjust quantities or relocate stock locations via modals.

Chronological Ledgers

  • Audit Ledger Trail: Comprehensive log entries mapping every stock transaction.
  • Transactional Options: Record Inbound additions, Outbound shipments, and Internal Transfers.
  • Transfer Guarantees: Automatically deducts from source and adds to destination hubs in a single safe database sequence.
  • Logged Notes: Force audit comments to track manual write exceptions.

Technical Architecture & Stack

Client Layer (Frontend)

  • React 19 & Vite: Lightning-fast compilation and highly efficient virtual DOM updates.
  • Context Auth: Encapsulates user profiles, login hooks, and token cookies client-side.
  • Lucide Icons & CSS: Slick interface styled with clean CSS variables and modern vector layouts.

API Server Layer (Backend)

  • Node.js & Express: High-performance async server handling REST API endpoints.
  • Modular MVC Layout: Separation of Concerns with dedicated routes, controller actions, models, and services.
  • express-validator: Strict request sanitization validating types prior to SQL queries.

Database Storage (MySQL)

  • Relational Integrity: Strict table relationships linked with foreign keys and cascading delete rules.
  • Unique Indexes: Prevents dual coordinates for identical products in the same warehouse center.
  • JSON Audit Columns: Stores state diff records natively in audit_logs for compliance.

AI & Analytics Engine

  • Google Gemini 2.5 Flash: Full natural language capabilities answering queries with live database context.
  • Local NLP Rules: Automated fallback patterns resolving low-stock warnings and anomaly reports locally.
  • Statistical Deviations: Custom math routines calculating transaction outlier spikes.

Backend API & Controller Design

Core API Endpoint Architecture

  • Auth Routes: Secure endpoints for registering accounts and logging in, generating JSON Web Tokens.
  • Item Catalog: REST routes (GET, POST, PUT, DELETE) handling global product catalog entries.
  • Physical Stocking: Location routes managing Rack/Shelf/Bin position edits and active stock lines.
  • Logistics Ledger: Transaction execute routes processing inbound stock additions, outbound shipments, and internal transfers.
  • AI Engine: Endpoints for automated forecasting metrics and natural language chatbot assistance.

MVC Transaction Controller Pattern

  • Validation: express-validator middleware intercepts and sanitizes requests before sql connection queries are made.
  • Atomic Transfers: Relational SQL transaction blocks execute warehouse stock transfers (checking source balance, subtracting units, and inserting into destination) to guarantee consistency.
  • Compliance logging: Every write-controller automatically logs actions to the audit table, archiving the delta states.
  • Centralized error catching: Global Express error handler isolates database crashes and feeds clean JSON back to the React UI.

AI-Powered Demand Forecasting

Predictive Replenishment Logic

  • Sales Velocity: Calculated dynamically as total outbound unit volume divided by elapsed ledger days.
  • Category Baselines: Automated fallback rates (e.g. Groceries: 12.5/day, Tech: 4.2/day) for new SKUs with short history.
  • Reorder Point (ROP): Calculated as: (Daily Sales Velocity * 5 Days Lead Time) + Safety Threshold.
  • Seasonal Multiplier: Dynamic demand multipliers adjusted by category (e.g. Summer bump of 1.45x for tropical fruits; Winter holiday bump of 1.30x for technology products).

Procurement Suggestions

  • Predicted 30-Day Demand: Estimates monthly requirements by applying seasonal factors to sales velocities.
  • Smart Buy-Orders: Recommends exact buy-order volumes using formula: (Predicted Monthly Demand - Current Stock balance).
  • Excel & PDF Exports: Compiles detailed forecast tables into CSV and print-ready PDF logs in one click.

Security & Anomaly Auditing

JSON-based Compliance Audit Logs

  • Database Trigger: Every write query executing on products, inventory, or users prompts an audit trail entry.
  • State Archiving: JSON database columns log pre- and post-values of objects for precise auditing.
  • Operator Accountability: Captures performing user account, action type (create/update/delete), and exact timestamp.
  • Immutability: Normal backend application routes prevent logs from being altered, guaranteeing compliance.

Statistical Anomaly Spike Detection

  • Sales Spike Logic: System computes averages and standard deviations on item outbound transaction histories.
  • Outlier Trigger: Flags any outbound order size exceeding the historical average by 1.5+ standard deviations.
  • Operational Safeguard: Alerts managers to potential stock shrinkage, billing errors, or fraud.
  • Contextual AI: LLM assistant references detected anomalies to answer natural-language auditing questions.
